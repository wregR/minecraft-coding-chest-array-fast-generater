# Coding Chest v0.3.0 — 16堆叠支持 / 16-stack support

## 简体中文

新增16与64堆叠混装编码箱，保留每箱最多50种、每种1件、54格全部占用的规则。最后4格自动调整命名纸和剪刀的配比，吸走任意编码物品1件后均为SS2→SS1；纯64堆叠箱的配方不变。

- 二进制组合编码、10～14进制信号编码均支持16堆叠物品。
- 校对页不再将16堆叠标为不支持；增加16堆叠筛选和带确认的恢复入口。
- 旧项目已排除的物品不会自动恢复，恢复后仍需校对重复目标。不可堆叠物品仍不参与编码。
- 材料表按实际装填统计；导出反读检查同时核对16/64物品、动态填充和材料数量。
- 更新中英文README。

安装：**Minecraft Java 1.21.0 / Fabric Loader 0.16.0+ / Fabric API 1.21 / Java 21**。用下方 `codingchest-0.3.0.jar` 替换旧版JAR，不要同时启用两个版本。建议先备份世界和项目。

测试：32项纯核心测试通过；46项完整测试中45项通过，1项环境专用断言跳过。原版比较器覆盖1326种组合和44200次单件移除。101种真实物品（含45种16堆叠）生成的12份不同进制/旋转投影，已独立反读验证槽位、地址、告示牌和材料表。

单机升级实测：在独立副本恢复44种16堆叠后，859种物品生成65个双箱和66块告示牌，导出校验通过；创造放置及全部196个方块的撤销成功，0处冲突。

这不是红石整机时序验收；独立多人服务器仍未实测。界面主要为中文。

## English

Adds mixed 16-stack and 64-stack encoder chests while keeping the 50-item-type limit, one item per type, and all 54 slots occupied. The final four slots dynamically balance named paper and shears. Removing one of any encoding item changes the comparator output from 2 to 1. All-64-stack chests keep the original recipe.

- Supports 16-stack items in binary combination encoding and base-10 through base-14 signal encoding.
- Item review now accepts 16-stack items, with a dedicated filter and a confirmed restore action.
- Exclusions in old projects are never cleared automatically. Check duplicate destinations again after restoring items. Unstackable items remain unsupported for encoding.
- Material lists use actual generated inventories. Independent export verification now checks mixed stack sizes, dynamic fillers, and material quantities.
- Updates both player guides.

Requires **Minecraft Java 1.21.0 / Fabric Loader 0.16.0+ / Fabric API for 1.21 / Java 21**. Replace the old JAR with `codingchest-0.3.0.jar` below; do not enable both versions. Back up worlds and projects first.

Tests: 32 pure core tests passed; the full suite has 45 passes and one environment-specific skip. Vanilla comparator checks cover 1,326 configurations and 44,200 single-item removals. Twelve exports across encoding bases and rotations, using 101 real items including 45 that stack to 16, passed independent checks of inventories, addresses, signs, and material lists.

Singleplayer upgrade check: restoring 44 excluded 16-stack items in a separate project copy produced 65 double chests and 66 signs for 859 items. The export passed verification; Creative placement and undo of all 196 generated blocks succeeded with no conflicts.

This is not an end-to-end redstone timing test. Dedicated multiplayer servers remain untested. The interface is primarily in Chinese.
