# Coding Chest v0.2.0

## 简体中文

游戏内生成编码全物品的编码箱阵列。

需要 **Minecraft Java 1.21.0、Fabric Loader 0.16.0+、Fabric API（1.21）和 Java 21**。下载下方的 `codingchest-0.2.0.jar` 放入 `mods` 文件夹；不要把 GitHub 自动附带的源码压缩包当作模组安装。

- F6 打开面板，F7 开关框选，左键和右键分别选择两个角点；快捷键可自定义。
- 支持多个选区和项目，读取方块、展示框和容器排版并校对物品。
- 支持10／11／12位二进制组合编码，以及10～14进制信号编码。
- 二进制为双层阵列，N进制为单层；每个双箱最多50种编码物品，自动拆箱和填充。
- 每箱附编码告示牌，起点附方向牌；支持预览、旋转、创造放置与撤销。
- 投影自动保存到当前游戏实例的 `schematics/codingchest/`，无需终端或手动解压。

目前只生成64堆叠物品的编码箱，不生成红石接线。完整扫描与放置需要创造模式和管理员权限。界面目前主要为中文；独立多人服务器尚未实测。请先备份世界。

验证：27项纯核心测试通过；39项完整测试中38项通过、1项环境专用断言跳过。单机实测815种物品生成62个双箱和63块告示牌，导出反读、框选、多选区保存、放置及撤销均通过。这不是红石整机时序验收。

## English

Generate filled encoder chest arrays for encoded item storage, entirely in-game.

Requires **Minecraft Java 1.21.0, Fabric Loader 0.16.0+, Fabric API for 1.21, and Java 21**. Download `codingchest-0.2.0.jar` below and place it in `mods`. GitHub's automatically generated source archives are not installable mods.

- F6 opens the panel. F7 toggles selection mode; left- and right-click set the two corners. Key bindings are customizable.
- Save multiple selections and projects; scan blocks, item frames, and container layouts, then review the items.
- Supports 10/11/12-bit binary combination encoding and base-10 through base-14 signal encoding.
- Binary arrays use two layers; base-N arrays use one. Each double chest holds up to 50 distinct encoding items, with automatic splitting and filler.
- Includes encoding signs, a direction marker, preview, rotation, Creative placement, and undo.
- Schematics save directly to the current instance's `schematics/codingchest/` folder. No terminal or manual extraction is needed.

Generation currently supports only items that stack to 64. Redstone wiring is not generated. Full scanning and placement require Creative mode and operator permissions. The interface is primarily in Chinese; dedicated multiplayer servers have not been tested. Back up your world first.

Validation: 27 pure core tests passed; the full suite has 38 passes and one environment-specific skip. Singleplayer testing generated 62 double chests and 63 signs for 815 items, with export read-back, selection, saved selections, placement, and undo verified. This is not an end-to-end redstone timing test.
