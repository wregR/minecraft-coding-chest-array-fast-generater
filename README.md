# Coding Chest · 编码全物品

**简体中文** | [English](README.en.md)

把游戏里摆好的全物品排版，变成装好编码物品的箱子阵列。

框选排版、确认编码、预览结果、导出投影，全程在 Minecraft 内完成。

## 能做什么

- 读取方块、展示框和容器排版，支持保存多个选区和项目。
- 支持二进制组合编码，以及 10～14 进制信号编码。
- 根据分组、单片、水道分配地址，在选定规则下优化编码箱数量。
- 自动装填双箱，并为每箱添加编码告示牌、为起点添加方向牌。
- 导出 `.litematic`、物品地址表、信号表和材料清单。
- 预览、旋转阵列，在创造模式放置，并撤销本次生成。

> 本模组生成编码箱，不生成整套红石电路。接线和机器时序需要按你的全物品设计自行处理。

## 安装

需要 **Minecraft Java 1.21（1.21.0）**、**Fabric Loader 0.16.0+**、对应版本的 **Fabric API**，以及 **Java 21**。

1. 从 [v0.3.0 发布页](https://github.com/wregR/minecraft-coding-chest-array-fast-generater/releases/tag/v0.3.0) 下载 `codingchest-0.3.0.jar`，和 Fabric API 一起放入游戏的 `mods` 文件夹。
2. 确保只安装一个 Coding Chest 版本，不要安装 `sources.jar`。
3. 启动游戏，进入世界后按 **F6** 打开面板。

无需 Python、终端或额外启动脚本。生成投影不依赖 Litematica；要加载、查看投影时再使用 Litematica。

当前只面向 1.21.0，不保证兼容 1.21.1 或其他版本。操作世界前建议先备份；完整扫描、放置和撤销需要创造模式及管理员权限（单机开启作弊，多人服需要 OP）。多人服使用完整功能时，服务端也要安装同一模组。

## 快速上手

1. **框选排版**：按 F7 开启框选，左键选第一个角点，右键选第二个角点。虚框显示选中范围，选点不会破坏或使用方块。
2. **保存选区**：按 F6，在「选区库」中命名保存。可以先保存多个区域，再逐个处理。
3. **确认结构**：载入选区，进入「识别 / 编码」。使用结构推测，或用 F8 依次采样首片各水道，确认内→外方向、单片间距、数量和组号。
4. **设置编码并扫描**：选择进制、码长、分组和水道顺序；多组排版要全部登记、扫描，不能只处理其中一段。
5. **校对物品**：在「物品校对」中处理读取问题、重复目标和不支持的物品，然后保存项目。
6. **生成结果**：在「生成 / 保存投影」中计算、预览，再点击「生成投影（自动保存）」。也可以设置原点和旋转后，在空气中创造放置。

这里的「单片」是沿走廊重复排列的储存模块，「水道」对应模块内的目标箱位。地址顺序始终是：**分组 → 组内单片 → 水道**。

升级旧项目时，已排除的16堆叠物品不会自动恢复。需要时在「物品校对」点击「恢复已排除16堆叠」，确认后重新检查重复目标，再保存；也可以逐个校对。

## 默认快捷键

| 按键 | 操作 |
| --- | --- |
| F6 | 打开面板，也可输入 `/codingchest` |
| F7 | 开关框选模式；开启后左键角点1、右键角点2 |
| F8 | 采样首片的下一个水道 |
| Shift + F8 | 按准星命中面采样附着物 |
| Ctrl + F8 | 清空首片样本 |

可在「选项 → 控制 → 按键绑定 → 编码全物品」修改，也可从面板点击「修改快捷键」。提示会跟随实际绑定更新。

## 编码与输出

| 编码 | 设置范围 | 编码箱排布 |
| --- | --- | --- |
| 二进制 | 10 / 11 / 12 位，1 / 2 / 4 / 8 组 | 双层组合编码 |
| N进制 | N = 10～14，三个字段分别输出信号值 | 单层信号编码 |

水道数不必等于进制，例如可以使用 **5水道 + 十进制信号**。二进制默认8水道。每组均从内向外编号，水道顺序可调整。

每个双箱最多装 **50种编码物品，每种1件**，支持16与64堆叠混装。前50格不足部分用命名纸各1张补齐，最后4格根据16堆叠种数自动调整纸和剪刀的配比。所有槽位均占用，吸走任一种编码物品1件后，比较器信号由2降至1。纯64堆叠时仍是第51格5张纸、末3格各一把剪刀。超过50种会自动拆箱，不会截断物品列表；材料表按实际填充数量统计。

投影自动保存到当前游戏实例的：

```text
schematics/codingchest/<项目名-时间-唯一编号>/
```

其中有可直接加载的 `encoder.litematic`、分享用 ZIP，以及地址、信号和材料表。每次生成使用新目录，不覆盖旧投影；点击「打开投影文件夹」即可找到。开启版本隔离时，请查看对应游戏实例的文件夹。

项目和选区保存在 `config/codingchest/` 下，退出游戏后仍会保留。

## 当前限制

- 支持16和64堆叠物品；不可堆叠及其他堆叠上限的物品暂不支持。
- 同一物品只能对应一个目标地址，冲突必须先校对。空位不会让后续地址前移。
- 自动识别是辅助功能，首片、水道和方向仍需要玩家确认。
- 创造放置仅允许目标位置为空气；撤销遇到后续改动会跳过冲突，不强行覆盖。
- 已完成本地单机测试；独立多人服务器尚未实测。
